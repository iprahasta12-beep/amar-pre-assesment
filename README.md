# Amar Designer — UX Pre-Assessment

Unzip this folder and open `index.html` in your browser. No installation or build is needed.

The page follows Figma frame `1022:2519`, including its Amar Designer logo and rocket illustration. It uses the uploaded project's plain HTML, CSS and JavaScript approach. On smaller screens, the form becomes a single column.

Participants enter their name, email, suggested improvements and design rationale. All fields are required. Submit Solution opens a review screen; Download Answers saves a JSON file. Edit Answers returns to the form without clearing it.

This is an offline frontend. Answers remain in memory while the page is open and are not sent anywhere. Refreshing or closing the page clears them. Download the JSON to retain a copy. There is no automated scoring or shared response collection.

The reference in the supplied Figma screen is a rocket illustration. To use a UI critique exercise, replace `assets/reference.png` with the intended screen and update the image's alt text and CSS dimensions as needed.

Files: `index.html`, `style.css`, `app.js`, `assets/amar-designer.png`, `assets/reference.png`.

Fonts use Inter/Roboto if already installed, with Arial as an offline fallback.
